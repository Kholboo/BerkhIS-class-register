# Бэрх ОУС - 10Б ангийн сурагчдын бүртгэл

## 1. Байршуулах (нэг удаа)
1. GitHub дээр шинэ репо үүсгэнэ (жишээ: `10b-class`).
2. Энэ хавтасны **бүх файлыг** (`index.html`, `data/`, `images/`, `.nojekyll`) репод оруулна.
   Лого: `images/Logo_mgl.png` файлаа `images/` хавтсанд хийнэ.
3. Repo -> **Settings -> Pages** -> Source: `Deploy from a branch`, Branch: `main` / `(root)` -> Save.
4. 1-2 минутын дараа `https://<нэр>.github.io/<репо>/` хаяг дээр сайт нээгдэнэ.

## 2. Багшийн token үүсгэх (нэг удаа)
1. GitHub -> Settings -> Developer settings -> Personal access tokens -> **Fine-grained tokens** -> Generate.
2. Repository access: **Only select repositories** -> зөвхөн энэ репо.
3. Permissions -> Repository -> **Contents: Read and write**.
4. Үүссэн token-г хуулна.
5. Сайт дээр доод хэсгийн **☁** товч -> багшийн нууц үг (анхны: `NNEE`) -> token-оо буулгана.

Token зөвхөн тэр багшийн хөтөч дээр хадгалагдана. Сурагчид token-гүй тул зөвхөн харна.

## 3. Санамж
- Репо public бол сурагчдын утас, имэйл, зураг нийтэд нээлттэй болно. Сурагчид насанд хүрээгүй тул анхаараарай.
- Анхны багшийн нууц үг `NNEE`-г **заавал солино** (🔑 товч).
- Лого хөтөч дээр хадгалагддаг, GitHub руу орохгүй.

## 4. Профайл үзэх нууц код
- Нүүр хуудсан дээр зөвхөн зураг, овог нэр, хүйс харагдана. Төрсөн огноо, утас, имэйлийг "Профайл харах" дарж **үзэх кодоор** нэвтэрсний дараа харна.
- Анхны үзэх код: `OTFF`. Багш доод хэсгийн **🔒 (user-lock)** товчоор солино. Код GitHub дээрх `students.json` дотор хэш хэлбэрээр хадгалагдаж, бүх хэрэглэгчид нэг кодоор ажиллана. Солихын тулд багшийн token тохируулсан байх ёстой.
- Анхаар: `students.json` файл репо public бол шууд уншигдана. Код зөвхөн хуудсан дээрх хамгаалалт юм.
